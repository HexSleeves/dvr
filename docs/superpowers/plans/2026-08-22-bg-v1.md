# bg v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build bg v1 — a macOS daemon (`bgd`) embedding jj-lib that auto-snapshots registered repos, materializes CoW workspaces, and serves a unix-socket JSON API, plus a thin `bg` CLI.

**Architecture:** Rust workspace, four crates: `bg-proto` (API DTOs), `bg-engine` (jj-lib wrapper, all repo logic), `bg-daemon` (axum server over UDS + FSEvents watcher + registry), `bg-cli` (produces both `bg` and `bgd` binaries; `bg` is a thin HTTP-over-UDS client). The daemon is the only writer to any repo store.

**Tech Stack:** jj-lib =0.44.0 (pinned; gix backend, pure Rust), tokio 1, axum 0.8 (UDS serve), hyper 1 + hyperlocal 0.9 (UDS client), notify 8 + notify-debouncer-full 0.7 (FSEvents), clap 4, serde/serde_json, thiserror/anyhow, tracing.

**Spec:** `docs/superpowers/specs/2026-08-22-bg-design.md`

## Global Constraints

- Rust ≥ 1.89 (jj-lib 0.44.0 MSRV), edition 2024.
- `jj-lib = "=0.44.0"` — exact pin. Its API is explicitly unstable; when a signature in this plan doesn't compile, the ground truth is the jj source checkout made in Task 1 (`~/.cache/jj-src`, tag `v0.44.0`) — especially `cli/src/cli_util.rs`, `cli/src/commands/git/init.rs`, `cli/src/commands/workspace/add.rs`. Adapt to the real signature; do not downgrade/upgrade the pin.
- For an EXISTING git repo, colocated init is `Workspace::init_external_git(settings, root, &root.join(".git"))` — NOT `init_colocated_git` (that one creates a fresh git repo).
- **Guardrail (spec §5): never auto-push.** The only code path allowed to spawn `git push` is `RepoEngine::push`. No background task may touch a remote.
- **Guardrail (spec §5): no implicit tracking.** `push` requires explicit `remote` + `bookmark`; pushing a bookmark that doesn't exist on the remote requires `create: true`.
- macOS only in v1. Workspace materialization uses APFS copy-on-write via `/bin/cp -Rc`.
- Unix socket paths must stay under ~100 bytes (macOS `sun_path` limit). Tests create sockets under `/tmp/bg-<pid>/`, never under `TMPDIR` (deep `/var/folders/...` paths).
- All state under a single dir resolved by `bg_daemon::state_dir()`: `$BG_STATE_DIR` if set, else `~/.local/state/bg`. Tests always set `BG_STATE_DIR`.
- Commit after every green test cycle (steps say when).

```rust
use std::{collections::HashMap, path::{Path, PathBuf}, sync::Arc};
use jj_lib::repo::{ReadonlyRepo, StoreFactories};
use jj_lib::workspace::{Workspace, default_working_copy_factories};

pub struct RepoEngine {
    pub(crate) root: PathBuf,
    pub(crate) settings: jj_lib::settings::UserSettings,
    pub(crate) repo: Arc<ReadonlyRepo>,
    pub(crate) workspaces: HashMap<String, Workspace>,
}

impl RepoEngine {
    pub async fn open_or_init(root: &Path, settings: jj_lib::settings::UserSettings) -> anyhow::Result<Self> {
        anyhow::ensure!(root.join(".git").exists(), "not a git repo: {}", root.display());
        let workspace = if root.join(".jj").exists() {
            Workspace::load(
                &settings,
                root,
                &jj_lib::default_backend_factories(),
                &default_working_copy_factories(),
            )?
        } else {
            let (ws, _repo) =
                Workspace::init_external_git(&settings, root, &root.join(".git")).await?;
            ws
        };
        let repo = workspace.repo_loader().load_at_head()?; // if load_at_head is async in 0.44: .await?
        let mut workspaces = HashMap::new();
        workspaces.insert("default".to_string(), workspace);
        Ok(Self { root: root.to_path_buf(), settings, repo, workspaces })
    }

    pub fn wc_commit(&self, ws: &str) -> anyhow::Result<jj_lib::commit::Commit> {
        let workspace = self.workspaces.get(ws).ok_or_else(|| anyhow::anyhow!("no workspace {ws}"))?;
        let id = self.repo.view().get_wc_commit_id(workspace.workspace_name())
            .ok_or_else(|| anyhow::anyhow!("no working-copy commit for {ws}"))?;
        Ok(self.repo.store().get_commit(id)?)
    }
}
```

```rust
use jj_lib::gitignore::GitIgnoreFile;
use jj_lib::matchers::{EverythingMatcher, NothingMatcher};
use jj_lib::working_copy::SnapshotOptions;

impl crate::RepoEngine {
    pub async fn snapshot(&mut self, ws: &str) -> anyhow::Result<bool> {
        let wc_commit = self.wc_commit(ws)?;
        let workspace = self.workspaces.get_mut(ws).ok_or_else(|| anyhow::anyhow!("no workspace {ws}"))?;
        let mut locked_ws = workspace.start_working_copy_mutation().await?;
        let options = SnapshotOptions {
            base_ignores: GitIgnoreFile::empty(),
            progress: None,
            start_tracking_matcher: &EverythingMatcher,
            force_tracking_matcher: &NothingMatcher,
            max_new_file_size: 64 * 1024 * 1024,
        };
        let (new_tree, _stats) = locked_ws.locked_wc().snapshot(&options).await?;
        if new_tree.id() == *wc_commit.tree_id() {
            locked_ws.finish(self.repo.op_id().clone()).await?;
            return Ok(false);
        }
        let mut tx = self.repo.start_transaction();
        tx.set_is_snapshot(true);
        tx.repo_mut().rewrite_commit(&wc_commit).set_tree(new_tree).write().await?;
        let new_repo = tx.commit(format!("snapshot workspace {ws}")).await?;
        locked_ws.finish(new_repo.op_id().clone()).await?;
        self.repo = new_repo;
        Ok(true)
    }

    pub async fn snapshot_all(&mut self) -> anyhow::Result<bool> {
        let names: Vec<String> = self.workspaces.keys().cloned().collect();
        let mut any = false;
        for n in names { any |= self.snapshot(&n).await?; }
        Ok(any)
    }
}
```
Drift notes: `set_tree` may be `set_tree_id(new_tree.id())`; `op_id()` accessor may be `operation().id()`; if `rewrite_commit` requires explicit descendant rebasing, add `tx.repo_mut().rebase_descendants().await?` before `tx.commit` (jj-cli does this — check `maybe_snapshot`). If `LockedWorkspace::finish` wants the operation from the *pre-tx* repo when nothing changed, mirror jj-cli exactly.

**Status** (in `engine.rs`): build `StatusResponse` by diffing `wc_commit.parents()[0].tree()` against `wc_commit.tree()` — use `MergedTree::diff_stream` (or `.diff()` iterator; see how `cli/src/diff_util.rs` walks entries) and map to `FileChange` with kind Added/Modified/Removed based on before/after presence. `RepoPath` → string via `path.as_internal_file_string()`.

pub async fn read_file(&self, rev: &str, path: &str) -> anyhow::Result<Vec<u8>> {

```rust
use notify_debouncer_full::{new_debouncer, notify::RecursiveMode};
use std::time::Duration;

pub fn spawn(state: crate::routes::AppState, roots: Vec<(bg_proto::RepoId, std::path::PathBuf)>) -> anyhow::Result<WatcherHandle> {
    let (tx, mut rx) = tokio::sync::mpsc::unbounded_channel();
    let mut debouncer = new_debouncer(Duration::from_millis(500), None, move |res| { let _ = tx.send(res); })?;
    for (_, root) in &roots { debouncer.watch(root, RecursiveMode::Recursive)?; }
    let roots_for_task = roots.clone();
    tokio::spawn(async move {
        while let Some(Ok(events)) = rx.recv().await {
            let mut dirty: std::collections::HashSet<bg_proto::RepoId> = Default::default();
            for ev in &events {
                for path in &ev.paths {
                    let internal = path.components().any(|c| {
                        let s = c.as_os_str(); s == ".jj" || s == ".git"
                    });
                    if internal { continue; }
                    if let Some((id, _)) = roots_for_task.iter().find(|(_, r)| path.starts_with(r)) {
                        dirty.insert(id.clone());
                    }
                }
            }
            for id in dirty {
                if let Ok(handle) = state.resolve(&id.0).await {
                    if let Err(e) = handle.lock().await.snapshot_all().await {
                        tracing::warn!(repo = %id.0, "auto-snapshot failed: {e:#}");
                    }
                }
            }
        }
    });
    Ok(WatcherHandle { debouncer }) // keep the debouncer alive; dropping it stops watching
}
```
`WatcherHandle` holds the debouncer; store it in `DaemonState` so it lives for the daemon's lifetime, and expose `watch_path(&self, id, root)` used by `register` (needs interior mutability — `std::sync::Mutex<Debouncer<…>>` is fine, calls are rare). The `roots_for_task` list also needs to grow on register: keep it in an `Arc<std::sync::RwLock<Vec<…>>>` shared between `spawn` and `watch_path`.
